# Starter Website

This repository contains a minimal, static starter website.

Quick start

- Serve locally (Python):

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

- Or with npm (runs the same command):

```bash
npm start
```

Deploy options

- GitHub Pages: push to `gh-pages` branch or use repository settings
- Vercel / Netlify: connect the repo and deploy the `main` branch

Next steps

- Replace content in `index.html` and add assets in subfolders like `images/` or `assets/`.
- Add a build step (Vite, webpack, etc.) if you want a modern workflow.
