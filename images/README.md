Images folder for the project.

Guidelines:

- Put image assets here (e.g., `logo.png`, `hero.jpg`).
- Keep filenames lowercase, use hyphens, e.g., `player-avatar.png`.
- Recommended sizes:
  - logos/icons: 32–256px PNG/SVG
  - hero/background: 1200–2000px wide (optimized)
  - thumbnails: 300–600px wide
- Optimize images for web (use WebP where possible, compress PNG/JPEG).

You can also add subfolders like `images/icons/` or `images/hero/` as needed.
